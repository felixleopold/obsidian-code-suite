This release changes nothing in how CodeSuite works: the README demo is now recorded from the real plugin, with live numbers.

## What's New

- The README hero clip is generated by `npm run record-hero`: it runs the real plugin in a real Obsidian, fetches the current download count, and shows the cursor, the Running state, live `$var` substitution, four themes, and an inline plot (#91)
  - Every release re-records it, so the numbers stay current.
  - It is 2.5 MB instead of 5.1 MB, with flat, undithered colours.

## Upgrade Notes

- No manual migration is required. Existing settings are preserved.
- The minimum supported Obsidian version remains 1.6.6.
